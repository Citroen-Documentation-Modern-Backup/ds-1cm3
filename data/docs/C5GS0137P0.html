3. Déshabillage
Déposer les sièges arrière .
3.1. Dossier arrière 1/3
Figure : c5gs1jpd
Déclipper ; À l’aide de l’outil [1350-ZZ] :
  • L’enjoliveur (2) (en "a")
  • Le coussin garni de dossier (1) (en "b")
Dégager le coussin garni de dossier (1).
Mettre en place curseurs sur les fermetures éclair (3).
Ouvrir la fermeture éclair (3).
Dégager le coussin garni de dossier (1).
Figure : c5gs1jqd
Déposer :
  • Le coussin garni de dossier (1)
  • L’armature de dossier (4)
3.2. Dossier arrière 2/3
Figure : c5gs1jrd
Déclipper ; À l’aide de l’outil [1350-ZZ] :
  • L’enjoliveur (5) (en "c")
  • Le coussin garni de dossier (7) (en "d")
Dégager le coussin garni de dossier (7).
Mettre en place les curseurs sur les fermetures éclair (6).
Ouvrir les fermetures éclairs (6).
Dégager le coussin garni de dossier (7).
Figure : c5gs1jsd
Déposer :
  • Le coussin garni de dossier (7)
  • L’armature de dossier (8)
3.3. Assise arrière (Monobloc)
Figure : c5gs1jtd
Déclipper la coiffe d’assise (9) (en "e") ; À l’aide de l’outil [1350-ZZ].
Dégager les fixations (en "f").
Figure : c5gs1jud
Déposer :
  • L’armature d’assise (10)
  • Le coussin garni d’assise (11)
4. Habillage
Procéder dans l’ordre inverse des opérations de déshabillage.
Vérifier le fonctionnement des différents équipements.
